# Security policy

Credoc moves funds through a smart contract on Arc. Please report vulnerabilities privately: open a GitHub security
advisory on this repository ("Report a vulnerability"), do not open a public issue.

- Acknowledgement within 72 hours, assessment within 7 days.
- Fix targets: critical 48 hours, high 7 days, others in the next release.
- Scope: `contracts/` (DocumentaryCredit), the relayer (`web/api/`), the web app and its server, the deployment files.
- The contract had an independent review before launch: see `docs/security-review.md`.
